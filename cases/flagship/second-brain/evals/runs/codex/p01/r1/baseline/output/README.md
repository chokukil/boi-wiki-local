# Local Private Second Brain

이 폴더는 외부 서비스나 전용 앱 없이 사용하는 로컬 개인 지식 저장소다. 모든 지식은 UTF-8 Markdown으로 기록하며, 오래 다시 쓸 내용만 보관한다.

## 지식 목록

### 결정

- [공유 지식 리뷰 일정](decisions/weekly-knowledge-review.md) — 활성

## 폴더 안내

- `decisions/`: 반복해서 적용할 결정과 그 근거
- `sources/`: 선별 전 원문 자료. 이곳의 내용이 자동으로 지식이 되는 것은 아니다.

새 자료를 검토할 때는 장기적으로 다시 사용할 내용만 별도 노트로 만들고, 일회성 내용은 지식 목록에 추가하지 않는다.
