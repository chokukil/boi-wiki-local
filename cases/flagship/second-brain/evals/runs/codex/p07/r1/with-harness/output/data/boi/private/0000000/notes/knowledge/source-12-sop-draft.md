# SYNTHETIC draft SOP — promotion is prohibited

## 초안 절차

1. 검토된 일정 결정을 찾는다.
2. 링크, 원본 해시, 충돌, 검토일을 확인한다.
3. 충돌은 사람 검토자에게 해결을 요청한다.
4. 정제 문서가 공유 자격을 갖춘 경우에만 공유 미리보기를 만든다.

## 적용 경계

- 이 절차는 초안이며 실행 승인을 받지 않았다.
- Team 게시용으로 승인되지 않았다.
- 충돌 해결과 공유 가능 여부 판단에는 사람 검토가 필요하다.

이 정보 문서는 원본을 변경하지 않고 초안 절차와 금지 조건을 보존한다. 실행 지침이나 공유 승인으로 사용하지 않는다.
