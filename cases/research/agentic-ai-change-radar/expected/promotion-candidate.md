# Agentic AI Change Radar — sanitized sharing candidate

공개 자료에서 확인된 변화 후보:

- OpenAI는 Python 중심의 초기 Agents SDK 설명 이후 현재 TypeScript SDK를 문서화하고 있다.
- MCP 2025-06 revision은 protected resource metadata와 resource indicators를 추가해 2025-03 authorization discovery 설명을 수정한다.
- AgentKit 발표는 visual workflow versioning, connector registry와 평가 기능 확장을 새 선택지로 제시한다.

이 내용은 SK하이닉스 적용 효과, 비용, 보안 적합성 또는 제품 선정을 확정하지 않는다. 해당 판단은 승인된 내부 검증과 사람 Review가 필요하다.
