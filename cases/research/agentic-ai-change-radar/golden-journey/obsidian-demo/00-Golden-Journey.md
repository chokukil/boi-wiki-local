# Agentic AI Change Radar — Obsidian walkthrough

이 Vault는 공개 Golden Journey의 고정 산출물을 읽기 쉽게 연결한 **sanitized Community 데모**입니다. 실제 사용자의 승인된 현재 지식, SK하이닉스 운영 검증, Verified 또는 production-ready 결과가 아닙니다.

## 한 번에 보는 흐름

1. [최초 기준 지식](01-T0-Baseline.md)에서 당시 판단과 unknown을 확인합니다.
2. [새 공개 자료의 업데이트 후보](02-T1-Update.md)를 봅니다.
3. [동일 Query의 답변 차이](03-Same-Query-Diff.md)에서 지식 성장을 비교합니다.
4. [충돌·오래된 판단·unknown](04-Review-Queue.md)을 사람이 검토합니다.
5. 승인된 변경만 다음 revision의 현재 지식이 됩니다.

## 사례에서 확인할 변화

- Node.js roadmap 판단은 현재 TypeScript 지원으로 수정됐습니다.
- MCP discovery는 후속 규격과 충돌해 구현 버전 검토가 필요합니다.
- Agent Builder 판단은 출시 이력을 보존한 채 stale·폐기 검토 후보가 됐습니다.
- 공개 자료만으로 SK하이닉스 적용성을 판단할 수 없어 unknown을 유지했습니다.
