# FAB Logistics Digital Twin — baseline contract validation

상태: **Community local contract evidence**. 공개 source record 5개로 Capture→Evidence→Query→Review handoff와 Local/Remote 경계를 실행한 baseline 검증이다. 실제 FAB 데이터, 유료 SEMI 표준 전문, 내부 domain review, 운영 효과 또는 production benchmark의 증거가 아니다.

`verify.ps1`은 Windows PowerShell만으로 fixture·artifact SHA256, 고정 Query, evidence/counterevidence/unknown, canonical handoff, Community 상태, privacy와 원격 전송 0건을 검사한다.
