# Scientific Foundation Model review queue

- `SFM-001` — perspective와 개별 task evidence의 역할을 혼합하지 않았는지 검토 필요
- `SFM-002` — empirical prediction과 explicit law satisfaction을 분리했는지 검토 필요
- `SFM-003` — preprint abstract를 full-text·peer-reviewed·reproduced로 과장하지 않았는지 검토 필요
- `SFM-004` — semiconductor 적용성은 unknown으로 유지했는지 검토 필요
- promotion 후보는 없다. 장기 durable claim도 원문 상태, reviewer, target, exact hash와 별도 사용자 승인이 필요하다.
