# Scientific Foundation Model Knowledge — baseline과 후보 답변 차이

| 답변 변화 | delta | 판정 |
|---|---|---|
| empirical prediction과 physics consistency 분리 → 물리 제약의 구현 위치까지 기록 | SFM-D01 | 일치 |
| model-level label → CLOUD-DEBYE의 downstream constraint와 model-wide 보장 분리 | SFM-D02 | 일치 |
| 일반화 범위 주의 → geometry·material·loading·manufacturability 경계 명시 | SFM-D03 | 일치 |
| code·data 공개 여부 → artifact availability와 reproduction success 분리 | SFM-D04 | 일치 |
| semiconductor 적용성 unknown → 필요한 방정식·오차·baseline·failure cost 구체화 | SFM-D05 | 일치 |

후보 답변에 delta 없는 새 결론은 없으며, delta가 답변에서 누락되지 않았다. 사람 Review 전에는 baseline snapshot을 유지한다.
