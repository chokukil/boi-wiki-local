# Dictionary

Local Private dictionary terms live here.

Use this folder for personal domain language, acronyms, aliases, and shop-floor phrases that help an agent understand your work. Keep entries simple: term, aliases, definition, examples, links, and source_refs.

For bulk candidate lists, keep curation decisions in local notes, manifest rows, or promotion drafts. Use actions such as `keep`, `replace_with_canonical`, `split_into_terms`, `alias_to_existing`, `exclude`, and `needs_parent_curation`. Detailed test/mode/variant terms should have a parent concept before Team/Public sharing.
